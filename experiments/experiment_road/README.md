# Ремонты, режимы движения и погода

Состояния движения 7/50: укорочение, отмена и восстановление. Проверены календарные и погодные поправки; отдельный holiday_service учитывает сценарий праздничного движения.

## Вывод

На платформе network_weather получил 0,87755, holiday_service — 0,87989. Локальный прирост относится к совместной модели; его нельзя целиком приписать погоде или ремонтам. Holiday_service меняет ноябрь, поэтому его отдельный эффект не измеряется сентябрьским срезом. Полный реестр ремонтов остальных маршрутов ещё не построен.

## Запуск

Открыть [DS1_Network_Weather_Competition.ipynb](DS1_Network_Weather_Competition.ipynb) в Kaggle, включить CPU и Internet, выполнить Run All. Предыдущие ноутбуки не нужны.
Обучение использует реальные метки организаторов с проверкой хешей. Маршрут 5 остаётся в полной сетке сабмита; прогнозы целые и неотрицательные.

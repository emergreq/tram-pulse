## Как читать результаты

- Метрика: WAPE-score = max(0, 1 − Σ|y − ŷ| / Σy), выше лучше. Δ — разница score, не проценты снижения ошибки.
- Локальная проверка обычно: train январь–август 2025 → отложенные метки сентября–октября. Этот период многократно использовался при выборе вариантов; он не является независимым тестом.
- Платформа оценивает ноябрь–декабрь 2025. Фактических пассажирских меток этого периода локально нет.
- Фактические внешние данные используются в competition-режиме. Это не всегда прогноз с информацией, доступной на 31 октября.
- При отклонении признаков показан итоговый fallback, равный базе. Δ=0 не означает, что все сырые кандидаты дали ровно нулевой эффект.
- Ноутбуки самостоятельны: Kaggle, CPU, Internet, Run All; предыдущие опыты запускать не нужно. Метки скачиваются из архива организаторов. Встроенные источники — снимок на дату опыта.

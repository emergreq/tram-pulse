## Запуск

Открыть [DS1_Schools_Kindergartens.ipynb](DS1_Schools_Kindergartens.ipynb) в Kaggle, включить CPU и Internet, выполнить Run All. Предыдущие ноутбуки не нужны.
Обучение использует реальные метки организаторов с проверкой хешей. Маршрут 5 остаётся в полной сетке сабмита; прогнозы целые и неотрицательные.
